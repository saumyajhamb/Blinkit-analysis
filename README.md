📌 Project Overview

This project is a Power BI data analytics dashboard built to analyze Blinkit’s sales performance, customer satisfaction and inventory distribution.
The goal was to transform raw Excel data into meaningful insights using data cleaning, DAX calculations, KPIs and interactive visualizations.
The dashboard helps stakeholders quickly understand business trends and identify areas for optimization.
________________________________________________________________________________________________________________________________________________________________________
🎯 Business Requirements

To conduct a comprehensive analysis of Blinkit’s:

1. Sales performance

2. Customer satisfaction

3. Inventory / item distribution

Using various KPIs and visualizations in Power BI to uncover insights and improvement opportunities.
_________________________________________________________________________________________________________________________________________________________________________
📊 Key Performance Indicators (KPIs)

1. Total Sales - Overall revenue generated from all items sold.

2. Average Sales - Average revenue per transaction.

3. Number of Items Sold - Total count of different items sold.

4. Average Rating - Average customer rating for sold items.

🛠 Tools & Technologies

1. Power BI Desktop

____________________________________________________________________________________________________________________________________________________________________________
🔄 Project Workflow

1. Data Collection - Imported dataset from Excel into Power BI.

2. Data Cleaning & Preparation - Handled missing values, corrected data types and removed duplicates and inconsistencies.

3. Data Modeling - Created relationships between tables where required and structured the dataset for efficient querying.

4. DAX Calculations - Built custom measures for KPIs such as Total Revenue, Average Revenue, Item Counts, Average Ratings

5. Dashboard Design - Designed interactive visuals including KPI cards, Bar charts, Pie/Donut charts, Filters, Slicers and Category & Outlet-level insights
_____________________________________________________________________________________________________________________________________________________________________________
📈 Dashboard Features

1. Interactive filtering by category, outlet type and item attributes.

2. High-level KPI summary for quick business understanding.

3. Visual comparison of sales vs ratings.

4. Distribution of items across outlets.

5. User-friendly layout for non-technical stakeholders.
_______________________________________________________________________________________________________________________________________________________________________________
🔍 Insights Derived

1. Identification of top-performing product categories.

2. Relationship between customer ratings and sales.

3. Outlet types contributing the most revenue.

4. Sales distribution patterns across inventory.
